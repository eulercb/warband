# Class balance coverage

The player balance pass covers all **12 classes and 24 subclasses**. The
Bard and Paladin pilot established the method. Ranger is the first new
class to enter the expanded comparisons. Earlier authored reviews and
playtests remain useful evidence for their individual mechanics.

Each subclass gets a representative fixed-encounter comparison with no
identity and both identities using native inputs. Check all 96 first-skill
picks for access to their identity mechanic in a focused solo-boss fixture.
Add a second first-pick profile when it materially changes the playstyle.
For stalls, compare selected same-size trios with healing, utility and
damage in the third slot. Use the [healer comparison](HEALER_PARTY_COMPARISONS.md)
to separate survival from clear-speed limitations.
Check that the intended mechanic actually triggers, then report solo and
party outcomes, survival, and identity-specific outcomes together. Record
a constrained controller or an unexercised effect explicitly.

Use grounded pressure, flight, movement, cover, adds and control to
differentiate kits. Keep class balance changes separate from boss behavior
changes during these comparisons. Evaluate ordinary ranks and opportunity
cost with actual reward draws, then test graft alternatives and displaced
slots. Apply confirmed fixes and rerun matched comparisons in the same
batch. Keep policies reproducible and vary the controller when outcomes
depend on a positioning or timing assumption.

All twelve classes and twenty-four subclasses now have representative
encounter results. Start the whole-roster power and progression pass, then
review usefulness and reward choices. The [development roadmap](DEVELOPMENT_STATUS.md)
records acquisition, graft, visual and encounter milestones.
